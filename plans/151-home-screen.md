# 151 — 첫 화면 구조 (시안 화면 B)

사양: `plans/design-spec-v2-screens-AB-2026-10-15.md` 화면 B. 의존 조사: 2026-10-18 읽기 전용 조사 3건(사이드바 입력·인기 목록·계약 테스트) + 계획자 직접 대조.

## 확인된 사실 (2026-10-18)
- 첫 방문(`mhl_landing_seen` 없음·쿼리 없음)은 소개 화면(`#view-landing`), 그 밖에는 지도 화면(`.lp` 사이드바 + `#view-map`). 화면 B 는 지도 화면이다. 소개 화면은 이번 범위 밖.
- `/api/search/popular` 는 `limit` 만 받는다(최대 30, 스냅샷 경로는 18행 상한). **지역 조건 없음**. `results[]` = `aptName, displayName, aptSeq, lawdCd, sigungu, umdNm, buildYear, recentDealDate, dealCount60d, avgDealAmount(60일 평균, 만원), lat, lng`. **최근 단건 거래가 없음**.
- 운영 실측(10-18 00:00Z): 12행 = 경기 9·부산 2·인천 1·**서울 0**. 시도별 개수를 보장하는 선정 규칙 없음(시군구당 2곳 캡뿐).
- 사이드바 노드를 **지우거나 옮기면** `doSearch`(#srchBtn·#bp·#mc·#wp·#pCnt), `renderPList`(#pList), `cl()`(#lr·#lA…), `renderBookmarks`(#bkCnt·#bkList), `cp()` 가 널 가드 없이 죽는다. **숨기기만 하면** id 접근은 모두 동작한다(`?region=` 자동 검색·`searchWithBudget`·값 이어 주기 포함).
- 데스크톱에서 검색 버튼·관심 단지 전체판·계약 타임라인·규제 표의 유일한 자리가 사이드바다. 관심 단지는 FAB 팝오버(축소판)가 있고 `.lp` 를 숨긴 뷰에서만 보인다.
- 행 클릭으로 상세 열기 = `goSearchResult(r)`(브리핑 TOP5·마커와 같은 경로, aptSeq 선택).

## 결정
1. **사이드바 DOM 은 그대로 둔다.** 지도 화면(데스크톱 >700px)에서만 `.lp` 를 숨기고 새 왼쪽 패널 `#homePanel`(420)을 보인다. **목록 화면은 지금처럼 사이드바 + 결과 그리드** — "조건에 맞는 단지 찾기"·관심 단지 전체·계약 타임라인·규제 표는 목록 화면에서 계속 쓴다. 내 상황 위저드는 보고서 화면으로(기존 `_wizPlace`) — 첫 화면에서 빠진다.
2. **가격 칸 이름은 "60일 평균가"** (시안의 "최근 거래가" 대신 — 필드가 없다). 제목 "최근 거래가 많은 단지"는 "거래가 많은"의 뜻이라 사실과 맞아 그대로.
3. **지역 칩은 받은 데이터에 있는 시도만**: "전국" + 결과에 1건 이상 있는 시도(법정동코드 앞 2자리, `backend/routes/region.js` SIDO_BY_PREFIX 와 같은 표). 시안 규칙 "샘플 값, 없으면 항목을 숨긴다". 서버 지역 조건 추가(RPC SQL 변경)는 하지 않는다.
4. 데이터는 `/api/search/popular?limit=12` — 지도 인기 마커와 같은 서버 캐시 키(`popular:12`), 지도와 목록이 같은 12곳을 보인다. 지도 SDK 와 무관하게 패널이 직접 부른다.
5. **검색창**: 지도 화면 데스크톱에서는 헤더의 `.hsearch` 노드를 오른쪽 검색 띠로 옮기고(높이 56), 다른 화면에선 헤더로 되돌린다(`_wizPlace` 와 같은 노드 이동 — 이중 입력칸 없음). 모바일은 옮기지 않는다.
6. **"다른 기능도 있어요"** 텍스트 버튼 4: 오늘의 브리핑 `sv('news')` · 대출 계산 `sv('calc')` · 청약 일정 `sv('subs')` · 규제 요약 `openRegSummary()`.
7. 검색(또는 이 지역 단지 보기) 결과가 지도에 있으면 패널 위에 안내: "조건에 맞는 단지 N곳을 지도에 표시했어요" + 목록에서 보기 · 인기 단지 다시 보기(`showPop`). 지도 위 인기 안내 카드(`#popTitleCard`)는 패널이 같은 설명을 하므로 데스크톱 지도 화면에서 숨긴다(DOM 유지 — 테스트 순서 계약).
7-1. 패널 폭: 1200px 이상 420(시안), 1199px 이하 340 — 시안에 분기 폭이 없어 계획자 결정(1024×768 실측: 420 이면 툴바 3줄·지도 높이 343).
8. 헤더의 사용량·알림·데이터 상태 등은 그대로(시안 헤더 축소는 별도 계획). 지도 확대·축소 44 묶음은 지도 SDK 기본 컨트롤이라 이번에 손대지 않는다.
9. **모바일(≤700px) 목록 시트는 151b 로 분리** — 시안에 끌기 동작·멈춤 위치가 없고, 기존 하단 요소(마커 시트 z380·하단 탭 z500·FAB z850·이 지역 단지 보기 버튼)와의 배치를 따로 정해야 한다. 151a 에서 모바일은 변화 0(375px 실측으로 확인).

## 하지 않는 것
최근 단건 거래가 지어내기 · 서울 칩 강제 노출 · 사이드바 노드 삭제 · 서버/DB 변경.

## 검증
verify 전체 · 새 계약 테스트(`backend/test/home-panel.test.js`) · 미리보기 데스크톱 1440/1280 + 375 실측(콘솔 오류 0, 패널 행 클릭 → 상세, 칩 필터, 검색 이동·복귀, 목록 화면 사이드바 유지, `?region=` 진입).

## 151b — 모바일(≤700px) 목록 시트 (2026-10-18)
같은 `#homePanel` 노드를 모바일에서 지도 아래 시트로 보인다(데이터·렌더 `_hpLoad`/`_hpRender` 공유).
- 시안 값: 위 모서리 16 · 그림자 `0 -4px 20px rgba(20,30,45,.1)` · 손잡이 36×4 · 제목 16/700 + "최근 60일" 12/500 · 행 최소 60(단지명 14/600·지역 12/500 / 가격 14/600·"거래 N건" 12/500) · 목록만 스크롤 · 아래 주 버튼 48 + 면책 12/500.
- **계획자 결정(시안에 없음)**
  1. 멈춤 3단계: 기본 = 지도 영역 52% 지점(시안 값), 펼침 = 위 8px(시안 "끌어올림"), **접힘 = 제목 줄**(지도를 넓게 보려는 사용자용 — 시안에 없음). 손잡이 끌기 = 가까운 단계로 붙음, 손잡이 누르기(키보드 포함) = 기본↔펼침(접힘이면 기본).
  2. 시트는 지도를 덮지 않고 `#mapEl` 을 시트 높이만큼 줄인다 — 지도 출처 표기(네이버 로고·OSM 표기는 가리면 이용 조건 위반)·"이 지역 단지 보기"(지도 안 하단)가 시트 위에 남는다. 펼침은 지도 크기를 다시 계산하지 않는다(기본 높이로 유지).
  3. 지도 캡션·안내·FAB·관심 단지 팝오버를 시트 높이만큼 올리고, 펼침이면 FAB 를 숨긴다. 마커 시트(#MSHEET)가 열린 동안 목록 시트를 숨긴다.
  4. 지역 칩·표 머리·긴 부제·약관 링크는 시안 모바일에 없어 숨김(약관은 ☰ 메뉴에 있음).
  5. 모바일 검색창은 헤더 그대로(헤더 개편은 별도), "다른 기능" 가로 버튼 줄은 넣지 않는다 — 같은 기능이 하단 탭(브리핑·도구)에 있고, 지도 위쪽은 범례·안내 칩·확대 버튼·위성지도 버튼이 이미 겹쳐 쓰는 띠(KKKKKKK-14 실측)라 한 줄을 더 얹으면 지도가 더 줄어든다.
