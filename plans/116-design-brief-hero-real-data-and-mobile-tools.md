## ① 랜딩 히어로 실데이터 카드 (P2)

### 지금 (실측 2026-09-26)
랜딩 우측 카드 영역이 위에서부터:
1. **"예시 · 가격 흐름 시각화(실제 데이터 아님)"** — 가짜 선 그래프(14억/10억/6억 눈금) + 캡션 "단지 선택 시 실거래 표·가격 위치·월별 거래량"
2. **"데이터 종합 점수 · 예시 · 60/100 거래보통"**
3. "TOP · 60일 거래량 · 실시간" — **실데이터**(예: 벽적골우성 · 수원시 영통구 영통동 · 1998년 · 5.0억 평균 · 57건)
4. "최근 7일 최고·최저 경신 · 실시간" — **실데이터**(204건 최고가 경신 · 64건 최저가 경신 · 2,682건 비교 가능)
5. "LTV · DSR · 10.15 규제" — 70% / 40% (무주택 비조정 기준)
6. "DATA SOURCE / LAST SYNC"
모바일(375×812)에서는 히어로 문구·CTA 바로 아래 **첫 카드가 1번(가짜 차트)** 이다.

### 바꿀 것
- 1번·2번(예시 블록 2개)을 **삭제**하고, 그 자리에 **3번 TOP 1위 단지의 실제 가격 흐름 카드 1장**을 둔다.
- 카드 내용(전부 이미 있는 데이터 — 새 API 없음):
  - 헤더: `실거래 · {단지명}` + 작은 배지 `국토부 신고` · 우측에 `최근 24개월 {N}건`
  - 본문: **월별 평균 실거래가 선 그래프(24개월)** — y 축 억 단위 3~4 눈금, x 축 6개월 간격 라벨. 점은 월별 거래 평균, 선은 가늘게. 색은 딥네이비 1색(다중 색 금지).
  - 하단 한 줄: `{최근 거래일} · {최근가}억 · 평균 {평균가}억` (tabular-nums)
  - 캡션(작게): `같은 단지 실거래 월별 평균 · 참고용 · 매수·매도 추천이 아닙니다`
- **거래가 적어 선이 빈약할 때의 상태**(중요 — 지어내지 않기): 24개월 거래가 12건 미만이면 그래프 대신 `최근 24개월 거래 {N}건 · 월별 추세를 그리기엔 표본이 적어요` 텍스트 상태 1종을 같이 그려라(시안에 **정상 상태 + 표본 부족 상태 2장**).
- 데이터 소스: 단지는 TOP 카드가 이미 받은 1위(`popular` 스냅샷), 시계열은 `/api/transactions/history`(Plan 102, 원본+이력 합산)의 최근 24개월. 실제 그래프는 상세 모달의 "장기 추세" 차트와 같은 계열이므로 **그 차트의 시각 언어(선 굵기·눈금·색)를 그대로 물려받는다** — 새 차트 스타일을 만들지 마라.

### 바꾸지 않을 것
히어로 좌측 문구·CTA 2개·"검색·단지분석은 가입 없이 무료…" 줄 · 3·4·5·6번 카드 · 헤더 · 모바일 히어로 칩(`mHeroChip`).

## ② 모바일 "도구" 바텀시트 (P5)

### 지금 (실측 2026-09-26)
모바일 하단 탭 5개: **브리핑 · 지도 · 목록 · 보고서(강조) · 대출**. 데스크톱의 "도구 ▾" 드롭다운(특약·청약·대출계산·규제 요약)은 `.htabs` 가 ≤700px 에서 숨겨져 **모바일에서 특약·청약·규제 요약에 닿을 탭이 없다**(특약 = 조건 반영 표준 특약 초안, 청약 = 청약Home 일정 + 가점 계산기 84점 — 둘 다 완성된 뷰).

### 바꿀 것
- 하단 탭 5번째 **"대출" → "도구"**(아이콘: 스패너/그리드 중 하나, 라벨 "도구"). 탭하면 **바텀시트**가 올라온다.
- 바텀시트 항목 **4개, 데스크톱 드롭다운과 같은 순서**: `특약 초안` · `청약 캘린더` · `대출 계산` · `규제 요약`. 각 항목 = 아이콘 + 제목 + 한 줄 설명(예: "대출 계산 — LTV·DSR·정책자금 4종 비교") + 우측 `→`.
- 시트 상단에 드래그 핸들, 하단에 `닫기`. 배경 딤. 높이는 내용만큼(4행 ≈ 300px). 열린 채로 다른 탭을 누르면 닫힘.
- 현재 뷰가 도구 중 하나(예: 대출)일 때 "도구" 탭이 **활성색**이고, 시트 안에서 그 항목에 체크 표시.
- **바꾸지 않을 것**: 다른 탭 4개 · 탭 높이(53px)·터치 타깃 · 데스크톱 · 각 도구 뷰 내부.

### 대안(시안에 같이 1장)
햄버거 드로어 하단에 "도구" 섹션(4항목)만 추가하고 하단 탭은 그대로 두는 안. 더 싸지만 발견성이 낮다 — 운영자가 둘 중 고를 수 있게 **비교용 1장**.

### 시안 산출물
- 모바일 375 라이트: 탭 상태 1장 + 시트 열린 상태 1장 + 다크 1장 + 드로어 대안 1장 = 4장
- 시안 프롬프트 한 줄 요약: "375×812 모바일 앱의 하단 탭 5개(브리핑·지도·목록·보고서·대출) 중 5번째를 '도구'로 바꾸고, 탭하면 바텀시트에 4항목(특약 초안·청약 캘린더·대출 계산·규제 요약)이 아이콘+제목+한 줄 설명으로 나열. 드래그 핸들·닫기·딤 배경. 딥네이비 #173A63, Pretendard, 라이트/다크. 다른 탭·헤더는 그대로. 비교용으로 햄버거 드로어에 '도구' 섹션만 넣는 대안 1장."
