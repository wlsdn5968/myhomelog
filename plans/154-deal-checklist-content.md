# 154 거래 단계별 체크리스트 — 항목과 공식 근거 (2026-10-30 확인)

원칙: 항목마다 근거를 붙인다. **법정 기한**(법령 원문 확인) / **공식 안내**(정부 기관 해설·문답) / **일반 안내**(공식 근거 없음 — 화면에 '일반 안내'로 표시, 출처 인용 금지).
확인 방법: law.go.kr 조문은 계획자가 크롬으로 원문을 직접 읽음(✓원문). 나머지는 조사 에이전트가 읽은 공식 페이지(✓기관).

## 확인하지 못한 것 (화면에 숫자를 쓰지 않음)
- 주택 취득 자금조달·입주계획서 제출 금액 기준(시행령 별표 — 페이지 열리지 않음). 2020년 기준(규제 3억·비규제 6억)은 옛값일 수 있다 → "제출 대상인지 중개사·신고관청에 확인".
- 등기 해태 과태료 금액, 전입신고 과태료 금액.
- 잔금 직전 등기부 재확인·근저당 말소 확인: 매매용 공식 권고 문구 미확인 → **일반 안내**.
- 기존 '잔금일을 월초~중순으로'(금융 일정에 유리): 공식 근거 없음 → 새 화면에서 뺀다.
- 부동산 거래신고법 2026-12-09 시행 예정 개정 내용(생활법령 공지) — 시행 전 재확인.

## 기한 계산 규칙 (시안 반영)
- 마감일 = 기준일 + N일(초일 불산입과 같은 결과). 양도세 = 양도일이 속한 달 말일부터 2개월 뒤 달의 말일.
- 민법 제161조(원문 확인): 기간의 말일이 토요일 또는 공휴일이면 그 익일로 만료 → 화면은 미루기 전 날짜를 보여 주고 이 규칙을 한 줄로 안내(공휴일 달력을 만들지 않는다).
- 전입신고는 잔금일 전입, 양도세는 잔금일=양도일 가정임을 마감일 아래 작은 글씨로 밝힌다.
- 라벨: '법정 기한'(마감일 계산 5개) / '법령'(날짜 없는 법령 항목) / '공식 안내' / '일반 안내'(근거 없음, 펼치기 없음).

## 구현 직전 원문 재대조 (2026-10-30, 계획자 크롬 law.go.kr)
- 부동산등기규칙 제60조 = 방문신청 시 등기의무자 인감증명 제출, **제62조 = 인감증명 등 발행일부터 3개월 이내** → 근거는 제60조·제62조(시안은 제60조만 — 바로잡음).
- 공동주택관리법 제30조 ① 장기수선충당금은 "해당 주택의 소유자로부터 징수" ✓. 주택도시기금법 제8조 ① 2호 "등기ㆍ등록을 신청하는 자" 국민주택채권 매입 ✓. 공인중개사법 제25조 ①·③ 확인·설명, 계약서 작성 때 서면 교부 ✓.
- **소득세법 시행령 제155조 ① (시행 2026-10-01, 개정 2026-09-30)**: 일시적 2주택 처분 기한 = 기존 집과 새 집이 모두 조정대상지역(새 집 취득일 기준)이면 **2년**, 그 밖에는 **3년**. 기존 집 취득 1년 뒤 새 집 취득 요건. 국세청 문답의 '3년'은 개정 전 → 화면 문구를 2년/3년으로 바로잡고 적용 시점(부칙 미확인)은 세무서 확인 안내.
- 소득세법 시행령 제154조 ①: 2년 보유, **취득 당시 조정대상지역이면 보유 중 2년 거주** → 시안 문구에 거주 요건 추가.
