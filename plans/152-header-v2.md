# 152 — 헤더 v2 (시안 화면 B 헤더)

사양: `plans/design-spec-v2-screens-AB-2026-10-15.md` 화면 B 데스크톱 헤더 — 높이 64(좌우 24, sf, 아래 line) · 로고 20/700 pri · 내비(브리핑·지도·목록·보고서·도구, 항목 36, 좌우 12, 14/600 ink2, 선택 pri/prit 모서리 6) · 다크 모드(아이콘 40×40) · 로그인(보조 40). 토큰은 `plans/design-spec-v2-2026-10-14.md` §1·§3.

## 확인된 사실 (2026-10-18, 읽기 전용 조사 2건 + 계획자 대조)
- 현재 헤더는 v2 이전 골드 테마(헤더 전용 토큰 `--hd-*`: 로고 사각·선택 탭 점 #C98A00, 배경 #F2F5FA)라 앱 나머지(v2 네이비)와 다르다. 높이 66.
- 로그아웃 데스크톱에 보이는 것: 로고(+부제 "HOUSING DATA TERMINAL") · 내비 5 · 로그인 · 알림 벨 · 데이터 상태 · 다크 모드. 사용량(#hUsage)은 한도 임박 때만(QUOTA-NEAR-ONLY).
- **헤더에서 빼면 끊기는 것(로그아웃 데스크톱)**: 알림 센터(#NTC — 벨 외엔 조건부 넛지뿐), 데이터 상태(#DSM — 헤더 버튼 외엔 #syncBanner 뿐이고 health 성공 때만 켜진다), 다크 모드(#themeToggle 이 유일), 로그인(#loginBtn 이 상시 유일), 지도 밖 화면의 검색(#hSearchInput — 지도 화면만 검색 띠로 이동).
- 헤더 CSS 를 검사하는 테스트 0건. `.htab` DOM 순서·개수는 `htabOrder`·`querySelectorAll('.htab')[N]` 인덱스 코드가 의존 — 바꾸지 않는다.
- 헤더 높이 하드코딩: `.clause-view,.biz-view{top:97px}`(66 + 동기화 띠 31), `.dmbg` 위 여백 78(헤더 아래 12 여유 — 64 에도 유효).

## 결정
1. 헤더 전용 토큰 `--hd-*` 를 v2 토큰에 연결(라이트·다크 같은 식 — 다크 값은 v2 토큰이 준다): 바탕 sf, 선 line, 탭 ink2, 선택 pri/prit, 메뉴 sf·ink·ink3·line, 로고 사각 pri/onpri. 골드 제거.
2. 데스크톱(≥701px): 높이 64·좌우 24 · 로고 글자 20/700 pri(부제 삭제 — 시안에 없음) · 내비 항목 높이 36·좌우 12·14/600 ink2, 선택 = pri 글자 + prit 바탕 + 모서리 6(골드 점 제거) · 다크 모드 40×40 텍스트 버튼(ink2) · 로그인 보조 40(sf·line2·모서리 8·14/600 ink).
3. **시안과 다르게 유지(근거: 다른 상시 경로 없음)**: 알림 벨(40×40 아이콘 텍스트 버튼), 데이터 상태(텍스트 버튼 40, 점+라벨 — 701~900px 은 기존대로 점만). 지도 밖 화면의 헤더 검색, 한도 임박 때만 보이는 사용량, 로그인 후 계정 메뉴도 유지.
4. 로고 사각 아이콘은 유지(701~1119px 은 기존 규칙상 글자가 숨고 사각만 남는다 — 없애면 로고가 사라진다).
5. 모바일(≤700px) 레이아웃은 그대로, 색만 같은 토큰을 따른다.
6. `.clause-view,.biz-view{top:96px}`(64 + 동기화 띠 실측 32.2 — 옛 주석의 31 은 틀렸고 66 시절에도 1.2px 겹쳤다).

## 하지 않는 것
탭 추가·삭제·재배열 · 알림/데이터 상태/로그인 기능 제거 · #syncBanner 변경(별도 판단).
