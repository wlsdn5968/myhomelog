## 148 — 기능 사이 길 잇기 (cafad3c)
조사(features.md, 계획자 원문 재확인): 서버 렌더 페이지로 가는 앱 안 링크는 푸터 1줄뿐인데 모바일에서 푸터 `display:none` · 지역 페이지 CTA 는 칩만 채우고 검색 안 함 · 단지 페이지 CTA "대출 한도·비용 계산" 은 상세만 엶 · 브리핑 CTA "지도·계산기와 함께" 는 브리핑만 엶 · 사이드바 입력과 계산기 입력이 따로 · 사용법은 로그아웃 데스크톱에서 경로 없음 · 복비 계산은 대출 계산 안 버튼으로만 · 지역 시장 요약 모달은 막다른 길 · 챗 오류 시 삭제된 `/api/legal` 호출.
- `/?region=` 진입 → 지도에서 자동 검색 1회(같은 탭·같은 값은 1회, 검색 일일 한도 1회 사용).
- 단지 페이지 CTA `&calc=1` → 상세의 평균가(>0일 때만)로 대출 계산 열기. 미리보기 실측: 까치마을 → 대출 계산 화면, 매수가 15.67억.
- 브리핑 CTA "앱에서 브리핑 보기", 지역 CTA "단지 찾아보기"(대출 계산은 이어지지 않으므로).
- 사이드바 → 계산기 값 이어 주기(빈 칸만, 단위 동일 확인: 억/억·억/억·만/만), 계산기 연소득 → 사이드바.
- 도구 메뉴·모바일 도구 시트에 "복비 계산"·"사용법", 모바일 드로어에 "지역별 실거래"·"브리핑 기록", 지역 시장 요약 모달 아래 `/region/<5자리>` 링크.
- 죽은 `/api/legal` 호출 삭제. 테스트 +11(원래 코드에서 10건 실패 확인) → 652.
