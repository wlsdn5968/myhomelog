# 156 — 목록 화면 개편 (시안 화면 D) — **시안 완료, 운영자 검토 대기 (2026-10-18)**

시안: Claude Design 프로젝트 `p/f486f1ca-bf1c-4b2c-bae5-a7921ca334d3`, 파일 `내집로그 리디자인 v2.dc.html` 맨 위 "화면 D(목록)". 요청문은 운영 실측·코드 조사의 사실만 담았다(아래 §1). **구현은 운영자가 시안을 본 뒤.**

## 1. 현재 사실 (2026-10-18 운영 실측 1440 + 코드 대조)
- 데스크톱 = 왼쪽 사이드바 `.lp` + 본문 `#view-list`(`.lgv` 그리드). 본문은 `renderListGrid()`(index.html), 사이드바 결과는 `renderPList()` — **같은 `props` 를 두 곳에 그린다**(doSearch 성공 시 `renderPList(); renderMarkers(props); renderListGrid();`).
- 사이드바 높이: "내 상황" 1,014px, 전체 스크롤 1,542px(운영 실측). 접힘 기본은 계약 타임라인·규제 표뿐.
- 본문 결과 순서: 분석 지역 줄 → 동네 시장(구별 시장 요약 최대 3) → 빨간 면책 상자 → 정렬(5종)·필터(전체·규제지역·비규제)·총 N건 → 카드. 페이지 없음(보통 15건).
- 카드 값: 단지명·구동·건축년도·점수 게이지·평균가(억)·상단 배지·LTV/최대 대출·꼬리표 최대 3·장점 62자·평형별 최근 평균 최대 3·비교 담기.
- **같은 이름, 다른 뜻**: 카드 상단 배지 "거래활발/거래보통/거래적음" 은 **점수**(75·50 기준, `_renderListCard`)로 정하고, 서버 꼬리표 "거래활발/거래보통" 은 **실제 거래 건수**(50·20 이상, `propertyService.js` `buildTags`)로 정한다. 같은 카드에 둘이 함께 나올 수 있다.
- 실제 꼬리표 10종: 거래활발(≥50건)·거래보통(≥20건) · 신축급(≤10년)·준신축(≤15년)·재건축연한(≥30년) · 다양평형(평형 4개+) · 실거래확인(다른 꼬리표 없을 때) · 주차여유(세대당 1.2+) · 대단지(1,000세대+)·중대단지(500세대+). **시안의 "역 도보권"·"구축" 은 없다(샘플).**
- 예산 안 판정: 평균가가 매수 예정가의 70~100% (`propertyService.js` budgetMinMan·budgetMaxMan).
- 다크 모드 결함: `setLstFilter` 가 비활성 필터 배경을 `#fff` 로 고정.
- 지도 화면의 영역 검색(`loadAptsInBounds`) 뒤엔 `props` 에 점수·꼬리표가 없어 목록 카드가 "분석 대기" 로 나온다(코드 조사, 브라우저 미확인).
- 사이드바 노드(#bp #mc #ch-* #pList #bkList #srchBtn 등)는 doSearch·generateReport·cl·renderBookmarks 가 널 가드 없이 읽는다 — **지우지 말고 숨기기만**.

## 2. 시안 요약 (Claude Design 설명 원문 요지)
- 사이드바 폭 320: 내 상황(보유 칩 2×2, 매수가·자기 자본, 희망 지역은 누르면 고르는 창), 단지 조건 칩 3, 주 버튼 "조건에 맞는 단지 찾기", 관심 단지, 계약 타임라인·규제 요약표는 텍스트 버튼. "더 정확한 보고서" 입력은 보고서 화면 링크로.
- 결과는 본문에만: 분석 지역 → 예산 안 건수 → 구별 시장 요약 텍스트 버튼 → 필터 칩 → 총 건수 → 정렬 버튼 → 카드.
- 상태 4종: 검색 전 · 검색 중(진행 막대, 단계 문구 3, 빈 카드 3) · 결과 · 0건(조건을 푸는 보조 버튼 3).
- 모바일: 위쪽 조건 요약 줄(누르면 조건 시트) · 정렬·필터 가로 스크롤 · 한 열 카드 · 하단 탭 5.
- 면책: 화면마다 "매수·매도 추천이 아니에요" 한 줄, 빨간 상자 제거. 꼬리표는 회색 한 종류, 최대 3.
- 점수: "거래활발·보통·적음" 이름 제거, 숫자(0~100)+남색 막대 한 가지, 좋고 나쁨 색 없음. 실제 거래량은 "6개월 평균 · 표본 N건" 으로 따로. 결과 위 한 줄 "점수는 과거 실거래 통계로 0부터 100까지 매긴 값이에요. 가격이 오를지 내릴지를 뜻하지 않아요." + "점수 기준 보기". 표본 적으면 한 줄 설명에 주의 문구.
- 시안이 새로 넣은 것(현재 기능 없음): "예산 밖 단지도 보기" 버튼, "점수 기준 보기" 내용, 15건 넘게 이어 보기.
