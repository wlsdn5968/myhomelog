## 왜 중요한가

### ① `hallType` 을 "구조" 라고 표기했다 — 사실이 아니다

`backend/routes/aptPage.js` 의 `buildAptInfoCard` 에 이 줄이 있다:

```js
  if (fac.hallType) rows.push(['구조', esc(String(fac.hallType))]);
```

`fac.hallType` 은 `buildFacility.js:209` 에서 `info.codeHallNm` 이다.

**DB 실측(2026-09-06)** — `apt_master.facility->>'codeHallNm'` 의 실제 값 분포:

| 값 | 행수 |
|---|---|
| 계단식 | 9,394 |
| 혼합식 | 2,565 |
| 복도식 | 2,278 |
| 기타 | 132 |

**이것은 복도유형(현관 접근 방식)이지 구조가 아니다.**
KAPT 는 **구조를 따로 갖고 있다** — `facility->'_dtl'->>'codeStr'` 의 실제 값 분포:

| 값 | 행수 |
|---|---|
| 철근콘크리트구조 | 10,633 |
| 철골철근콘크리트구조 | 2,310 |
| 철골콘크리트구조 | 617 |
| 콘크리트구조 | 360 |
| 조적구조 | 56 |

즉 **"구조" 라는 라벨을 계단식/복도식에 붙이면, 진짜 구조 값이 따로 있는데도 다른 것을 구조라고
말하는 것**이다. 절대 룰 ②(환각 차단 — 정확한 표기)에 어긋난다.

⚠ 이건 **계획자(나)의 계획서 잘못**이다. 계획 063 에 "구조"라고 적었고 실행자가 `buildFacility` 에서
가장 가까운 필드를 골랐다. 실행자는 이 불일치를 **정직하게 보고**했다.

### ② 거래가 0인데 "국토교통부 실거래 신고 자료 정리" 라고 적는다

`aptPage.js` 의 `desc` 분기:

```js
  const desc = facts.length
    ? `${aptName}(${region}${umd ? ' ' + umd : ''}) ${facts.join(' · ')}. 국토교통부 실거래 신고 자료 정리 — 매수 추천이 아닙니다.`
    : `${aptName}(${region}${umd ? ' ' + umd : ''}) 국토교통부 실거래 신고 자료. 최근 24개월 거래 기록이 없습니다.`;
```

063 이 `facts` 에 **KAPT 출처의 세대수·준공년도를 push** 하도록 바꿨다. 그래서 거래가 **0건**인
페이지에서도 `facts.length > 0` 이 되어 **첫 번째 분기**를 타고,
`"… 1,601세대 · 2001년 준공. 국토교통부 실거래 신고 자료 정리 — …"` 가 된다.

**두 가지가 틀렸다**: ⓐ 거래가 없는데 "실거래 신고 자료 정리" 라고 말한다
ⓑ 그 사실들의 출처는 국토부가 아니라 **KAPT** 다.

⚠ 이 페이지는 `noindex` 라 검색 영향은 없지만, **사실과 다른 서술**인 것은 그대로다.
실행자가 이것을 "부수 효과"로 정직하게 보고했다.
