# 195 보안 점검: 중국 클라우드 수집기 (2026-11-12 밤, 운영자 요청)

## 결론
침입이나 정보 유출 흔적은 찾지 못했다. 공개 화면이 부르는 공개 API를 자동 브라우저가 대량으로 읽은 수집(스크래핑)이다.
운영자 지시로 중국(CN)과 수집기 ASN 2곳을 Vercel 방화벽에서 차단했다(규칙 "Block China and scraper ASNs", Deny, 게시 직후 23건 차단 확인).

## 왜 막히지 않았나
1. 공개 데이터 서비스라 공개 API는 로그인 없이 열려 있다(설계).
2. 요청 제한이 IP 기준이고 인스턴스 메모리에 있다. 수집기는 최소 30개 이상의 IP로 나눠 IP당 하루 498건 이하로 들어왔다(전체 상위 IP 5위가 498건이고 Tencent IP는 상위 5에 없음).
3. 평범한 크롬 UA로 자바스크립트를 실행해 봇 이름 차단(vercel.json)에 걸리지 않았다.
4. 방문 기록은 봇과 사람을 가리지 않고 센다(IP당 하루 30건 상한은 8b00a19 에 있다).

## 남은 위험과 할 일
- Vercel 계정 2단계 인증 꺼짐(화면 배너). 계정이 털리면 전부가 털린다. 운영자가 켠다.
- 저장소 공개: 비밀값은 없지만 코드 구조가 공개된다. 비공개 전환은 운영자 결정(GitHub 설정).
- 비밀번호가 있는 이메일 계정 1개(2026-05-03 생성, 로그인 기록 없음). 앱은 비밀번호 로그인을 쓰지 않는다(OTP, 구글, 카카오).
- 미국, 프랑스 가정용 회선(RCN, Charter, SFR, Starlink)에서 같은 순서의 요청이 화면 1회 분량씩 보인다. 사람인지 우회 수집기인지 미확인. 늘면 Vercel 무료 봇 보호(Challenge) 검토.
