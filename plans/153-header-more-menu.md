- 알림 센터 `openNtc()`(로그인 불필요, 카카오 알림만 로그인 필요) · 데이터 상태 `openDataStatus()` · 서비스 정보·사용량 `openSettings()`(#SM) · 사용법 `sv('guide')`. 로그아웃 데스크톱에서 #SM 을 여는 상시 경로는 현재 없다.
- 빨간 점 조건 = `_updateNtcDot()` 의 `!(_kkoLinked || _pushOn)` (로그인 무관).
- 사용량 표시 `_syncHUsage()`: 검색 남은 ≤2·채팅 남은 ≤3, 무제한이면 숨김. 장애 칩 = `#apiSt`(`chkAPI` 2회 실패 시).

## 결정안 (시안 미정 3건)
1. 위험 색: 시안 값 #B4473C·#F7E7E5·#8E3128 을 라이트 그대로, 다크는 기존 앱 토큰 `--red`(#FCA5A5)·`--redL`·`--danger-bd` 를 쓴다(새 값 지어내지 않음). 대비는 구현 때 계산해 기록.
2. 남은 검색 표시 기준: 현행 그대로(검색 ≤2·채팅 ≤3). 칩 문구는 기존 "오늘 남은 검색 N · 채팅 N" 구조 유지.
3. 메뉴 여닫기: 기존 도구 메뉴·계정 메뉴와 같은 방식(버튼 클릭 토글, 바깥 클릭·ESC 닫기, aria-expanded). 장애 칩 문구는 현행 "서버 오프라인" 을 해요체로 — "서버에 연결되지 않아요".

## 범위
데스크톱(≥701px) 헤더: 벨·데이터 상태 버튼 → 더보기 메뉴(로그아웃) / 아바타 메뉴 항목 추가(로그인), 빨간 점 이동, 남은 검색·장애 칩 시안 모양. 계정 메뉴의 "다크 모드" 항목은 시안 C2 목록에 없음 → 헤더 다크 아이콘이 있으므로 제거 여부도 검토 시 확인.
