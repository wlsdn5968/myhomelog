# 내집로그 서비스 전면 검토 — 2026-10-14

**방법**: 운영 사이트를 실제 화면으로 점검(운영자 크롬 = 로그인 상태 데스크톱, 내장 브라우저 = 로그인 안 한 신규 방문자 데스크톱·모바일 375px) + 공개 API 전수 호출(읽기만) + 코드 대조(file:line). 추측은 넣지 않았고, 확인 못 한 것은 맨 끝에 따로 적었다.

## 1. 한 줄 판단
데이터 기반(실거래 181만 건·매일 적재·공식 출처·면책 원칙)은 경쟁력이 있다. 그러나 **겉모습과 첫 경험이 그 기반을 깎아 먹는다** — 화면이 기능 과밀·이모지·내부 용어로 "AI 가 대충 만든 도구"처럼 보이고, 랜딩이 약속하는 핵심 기능(맞춤 보고서)은 지금 Redis 장애로 503 이다.

## 3. 약점 (심각도 순)
### A. 지금 고장·강등 (운영)
1. **Upstash Redis 무료 한도 초과** → 유료 AI 맞춤 보고서·특약 503(랜딩·모바일 배너의 주 버튼이 실패), 요청 제한 해제, 관측 데이터 소실. 챗은 Plan 133 으로 복구.
2. **응답 속도**: 단지 분석 5.2s · 신고가 기록 3.9~5.0s · 검색 첫 호출 3.6s · 지역 페이지 최대 7.0s(Redis 캐시 미스 영향 가능).
3. **DB 87%(437/500MB)** — 경보선 넘음. 11-01 다음 자르기 전까지 여유 약 28MB.
4. 공개 키로 대형 테이블 읽기 가능(Plan 129 2단계 SQL 미적용 — 운영자 실행만 가능).

### C. UX
- **첫 화면 과밀**: 지도 화면 왼쪽에 "내 상황" 입력 폼(필수 3단계+선택 칩 약 10개)·관심 단지·계약 타임라인·규제·설정 6개 섹션 + 지도 위 인기 TOP12 팝업 + 필터 버튼 + 챗 버튼. 무엇을 먼저 할지 안내가 없다.
- **개발자식 안내**: 지도 상단 "마커클릭=팝업 | 더블클릭=상세리포트".
- **화면 간 숫자 불일치**: 같은 은마가 상세 모달 "최근 29건 평균 34.56억" / 단지 페이지 "24개월 109건 34.15억" / 챗 "최근 6개월 31건 34.8억" — 기간이 다른데 표시가 약해 혼란.
- **원칙과 충돌하는 표현**: 랜딩 "객관적 점수로 정리한 매수 결정 도구"(→ Plan 138 정정), 상세 탭 "🎯 가격 시그널", API 필드 `buySignal`.
- **모바일**: 하단 내비 5탭은 좋으나, 금액 입력칸 안내 문구가 잘리고 별·챗 떠 있는 버튼이 입력 영역을 가린다. 지도 첫 화면을 보고서 배너가 덮는다.
- **서버 렌더 페이지**: 앱으로 돌아가는 메뉴가 첫 화면에 없음. 브리핑 지표 줄에 가로 스크롤바 노출.
- 첫 방문(서버 콜드) 때 랜딩 "LAST SYNC" 가 "—"로 비는 경우(새로고침 시 채워짐).

### D. 접근성·기술 부채
- 클릭되는 div/span 약 120개 중 role="button" 1개, tabindex 10곳 → 키보드 조작 어려움. aria-live 0(토스트 낭독 안 됨).
- 프런트가 1MB 단일 HTML(스크립트 한 덩어리 약 578KB) — 고칠 때마다 회귀 위험이 크다.
- 개인정보처리방침 §5·§6 이 실제 처리와 다름(Plan 136 수정안, 게시는 운영자 확인).
- 결제 페이지 Sentry 10.69.0·SRI 없음(결제 주제라 보류).
