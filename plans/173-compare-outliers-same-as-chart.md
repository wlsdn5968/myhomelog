# 173 비교 창 동떨어진 거래 기준 = 가격 차트 — 2026-10-30

**운영자 승인**: 2026-10-30 "권고대로 진행해줘. 승인할게" (권고 = 비교 창 이상치 기준을 Plan 171 차트와 같게).

## 왜
- 비교 창(`analysisService._compareOne`)은 `filterAnomalies`(같은 평의 기간 전체를 한 번에 MAD, 20건 이상이면 2.5×MAD)로, 단지 상세 차트(Plan 171 `_pcOutliers`)는 시점마다 앞뒤 이웃과 비교해 거래를 뺐다. 같은 단지인데 두 화면이 서로 다른 거래를 뺐다(10-18 '화면마다 가격이 다름'과 같은 종류).
- 옛 기준은 오르는 흐름이 있는 2년치를 한꺼번에 보며 정상 거래까지 뺐다(아래 실측).

## 변경 (backend/services/analysisService.js)
- `localOutliers(transactions)`: 차트와 같은 규칙 — 평형 = 전용㎡/3.3058 반올림, 앞뒤 90일 이웃(3건 미만이면 180일, 자신 제외 3건 이상)의 중앙값에서 max(20%, 3.5×MAD) 초과. 중앙값은 짝수 개면 가운데 두 값 평균(프런트와 같은 식).
- `_compareOne`: 거래를 `dealMonths + 6`개월 받아 판정한 뒤 기간으로 자른다(기간 첫 달 거래도 앞쪽 이웃으로 판정 — 차트는 전체 이력으로 판정한다). 앞쪽 6개월은 건수·면적대·가격 흐름에 넣지 않는다. 뺀 건수는 `excludedTx`.
- 면책 문구에 기준을 적었다.
- `filterAnomalies` 의 다른 사용처(상세 분석 `analyzeApt`, 가격 위치)는 그대로 — 이번 승인 범위 밖.
