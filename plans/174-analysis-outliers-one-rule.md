# 174 상세 분석도 같은 동떨어진 거래 기준 — 2026-10-30

**운영자 승인**: 2026-10-30 "권고대로 진행해줘. 승인할게" (권고 = 상세 분석의 가격 위치 백분위·시세 요약도 차트·비교 창과 같은 기준).

## 발견 (코드 원문 + 운영 실측)
- `analyzeApt` 가 `filterAnomalies`(옛 기준)로 거른 표본을 `calcPricePercentile` 에 넘기고, 그 함수가 안에서 **한 번 더** `filterAnomalies` 를 돌렸다(이중 적용).
- 배포 전 운영 `/api/analysis`: 상계주공7(고층) 표본 75 · 제외 7 · 분석 68건인데 백분위 표본 `percentileN` 65(안에서 3건 더 뺌).
- 화면 문구 "(±30% 초과 가격)"은 옛 기준의 5건 미만 예외일 뿐 실제 규칙(MAD)과도 달랐다.

## 변경
- `analyzeApt`: 거래를 12개월(분석 6 + 앞쪽 6) 받아 `localOutliers`(차트·비교 창과 같은 규칙)로 판정한 뒤, 표본은 예전과 같은 최근 6개월(`txWindowMonths(6)`, 한국 시간 달)로 자른다. 표본 건수·거래량·월별 거래량은 그대로 6개월.
- `calcPricePercentile`: 안쪽 재필터 제거(입력이 이미 거른 표본).
- `filterAnomalies` 삭제(사용처 0). 세 화면(차트·비교 창·상세 분석)이 같은 규칙 하나.
- 분석 캐시 키 `analysis:v2:` — 배포 직후 1시간 동안 옛 기준 결과가 새 문구와 섞이지 않게.
- 화면 문구: '이상 거래' → '다른 거래와 동떨어진 거래', 기준 설명(가격 그래프의 빈 원과 같은 기준).
