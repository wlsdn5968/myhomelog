## 2. 수정안 (문구)
§5 처리 위탁 표
- Upstash 행: 위탁 업무 `속도 제한·일일 사용량 집계·응답 캐시 (접속 IP 또는 회원 식별자, 답변하지 못한 채팅 질문 최근 50건(80자 이내))` · 보유 기간 `속도 제한·일일 한도: 당일 자정(한국 시간)까지 / 답변하지 못한 질문: 최근 50건만 유지(새 질문이 들어오면 오래된 것부터 삭제)`
- Sentry 행: 위탁 업무 `오류·성능 모니터링 (쿠키·요청 본문·IP 제외, 비밀값 마스킹)` · 보유 기간 `30일` ← §3 확인 뒤 확정

§6 국외이전 표
- Anthropic 행: 이전 시점 `AI 기능(단지 리포트·특약 분석) 사용 시 / TLS 암호화 전송`
- Sentry 행: 이전 항목 `오류 발생 시 및 요청 표본(약 10%)의 요청 정보 — 쿠키·요청 본문·IP 제외, 비밀값 마스킹` · 이전 시점 `오류 발생 시·표본 요청 시 / TLS 암호화 전송` · 이용 기간 `30일` ← §3 확인 뒤 확정
- **Upstash 행 추가**: `Upstash, Inc. | 미국 | 접속 IP 또는 회원 식별자, 답변하지 못한 채팅 질문(80자 이내, 최근 50건) | 서비스 이용 시 / TLS 암호화 전송 | 당일 자정까지(질문은 최근 50건만 유지)`

## 3. 확인 필요(게시 전)
- Sentry 조직의 요금제(Developer 면 30일, Team 이면 오류 90일·성능 30일 → 문구를 "오류 90일, 성능 표본 30일" 로). Sentry 설정 Subscription 화면에서 확인.
- 처리방침 시행일·개정 이력 표기(파일 상단·하단의 시행일 줄)를 함께 갱신.

## 4. 하지 않는 것
- 동작 변경으로 문구를 맞추기(예: 질문 원문 보관 중단) — 원하면 별도 계획. 결제·토스페이먼츠 행 변경(결제 주제는 운영자가 꺼낼 때만).

## 5. 2026-10-18 진행 (초안 브랜치 `preview/privacy-136`, 커밋 adb4859 — 운영 미반영)
- **코드 재대조(10-18)**: 위 §1 사실이 그대로임을 확인 — AI 호출은 `routes/report.js:256`·`routes/clause.js:117` 두 곳 · 요청 제한 키 `u:<회원 ID>`/`i:<IP>`(`middleware/rateLimit.js:36-37`, Upstash 제한기) · 일일 한도 키 `dl:<scope>:<날짜>:<i|u>:<값>` 원값(`dailyLimit.js:176`, `getLimitIdentity`), KST 자정 만료 · 답 못한 질문 `chatint:misses` 80자·최근 50건·만료 없음(`chatDataRouter.js:816-817`) · Upstash 는 REST(https 주소 형식).
- **성능 표본 비율**: 코드 기본값은 백엔드·브라우저 모두 0.1 이지만 서버 환경변수 `SENTRY_TRACES_SAMPLE_RATE` 는 계획자 권한으로 조회 불가(Vercel 403) → 문구는 "일부 요청 표본"(숫자 없음).
- **Sentry 공식 보관 기간(10-18 재확인)**: 오류 Developer 30일·Team/Business 90일 / 성능(span) 30일, Business 이상은 표본 13개월, 트랜잭션 과금 Team/Business 는 90일. 요금제에 따라 문구가 달라 "최대 90일" 같은 일괄 문구도 안전하지 않다. 계획자는 Sentry 로그인 상태가 아니라(운영자 크롬 → 로그인 화면) 확인 못 함 → 초안에 "[Sentry 요금제 확인 후 확정]".
- **§13 사전 고지 의무 발견**: 처리방침 §13 이 "변경 시행 7일 전 공지, 정보주체 권리에 중요한 변경은 30일 전" 을 약속한다. 앱에 공지사항 기능은 없고 v1.1·v1.2 는 개정일 당일 바로 적용됐다. 국외이전 항목 추가(Upstash)가 "중요한 변경" 인지는 법적 판단 → 계획자가 정하지 않음. 초안에 "[시행일 결정 대기]".
- **남은 결정(운영자)**: ① Sentry 요금제(설정 → Subscription) ② 고지 방식·시행일(예: 처리방침 상단에 개정 예고 + 30일 뒤 시행이면 7일·30일 해석 모두 충족).
