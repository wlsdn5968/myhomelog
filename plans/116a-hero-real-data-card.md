## Step 1 — 1위 단지의 `apt_seq` 확보
`popularService.js:169` 의 반환 객체에 `aptSeq` 가 있는지 확인. 없으면 스냅샷/RPC 가 주는 `apt_seq` 를 그대로 실어라(MV 행에 있다). 스냅샷 테이블(`popular_apts_snapshot`)에 없다면 **랜딩 로더에서** `/api/search/apt?q=` 로 1건 조회하지 말고 — 대신 백엔드가 인기 목록을 만들 때 `apt_seq` 를 포함하도록 고친다(1곳).

## Step 2 — 프론트: 예시 블록 2개 삭제 → 실데이터 카드 1개
- `:2973-2994` 의 두 카드를 지우고 그 자리에 카드 1개(`id="lv-heroChart"`): 헤더·SVG 컨테이너·하단 한 줄·캡션. 초기 상태는 **스켈레톤**(빈 선 + "불러오는 중") — 값을 지어내지 않는다.
- 로더 `_loadHeroChart(top)`: 랜딩이 TOP 카드를 채운 직후(1위 단지가 정해진 시점) 호출. `/api/transactions/history?seqs=${aptSeq}` → 월별 합산 → 최근 24개월 → `n = Σ건수`.
  - `n >= 12`: 장기 추세 차트의 렌더 함수로 선 1개(색은 CSS 변수 `--acc` 계열이 아니라 시안 값 `#173A63`/다크 `#9DB8DA` — 기존 다크 토큰이 있으면 그것을 쓰고 새 색을 만들지 마라).
  - `n < 12`: 타임라인 상태(시안 1d) + 캡션 교체.
  - 실패: 카드에 `실거래 흐름을 불러오지 못했어요` 한 줄 — **예시 데이터로 대체하지 않는다**.
- 하단 한 줄의 `{최근가}` = 24개월 안 최신 거래의 금액(원본 행이 아니라 월별 집계에서는 최신 월 평균) — 시안 문구가 "5.2억" 처럼 단일가이므로, `/history` 집계에 최신 거래가 없으면 **"최근월 평균 5.2억"** 으로 라벨을 바꿔 사실에 맞춘다.
- 모바일: 이 카드가 CTA 바로 아래 첫 카드가 된다(현재 DOM 순서 그대로라 추가 작업 없음). 375px 에서 SVG 는 `viewBox` 로 축소.

## Step 3 — 테스트 (`backend/test/hero-real-data-card.test.js`)
