감사하지 않은 범위: `backend/routes/report.js`, `backend/services/propertyService.js`, `backend/routes/search.js` 의 본문 대부분, 화면 16,500줄 가운데 표본으로 본 곳 밖, 운영 DB 와 Redis 와 CDN 의 실제 값, 새 인스턴스의 모듈별 읽기 시간.
