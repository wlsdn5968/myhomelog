# 185 카카오맵 1대1 대조 전수조사 (2026-10-31)

읽기 전용 조사. 운영 DB·코드 변경 없음. 운영자 요청: "카카오맵이랑 우리 서비스의 매물들이랑 1대1로 무조건 비교 … 핀이 잘못찍히거나 a,b로 나눠져있다거나, 관리사무소나 이런 이름 … 에러가 있는 단지들 전수조사".

## 방법
- 범위: 관리 지역 125곳. 공식 단지 14,703 · 국토부 신고 이름 28,134(최근 180일 거래 17,962) · 신고 이름 좌표 19,353.
- 1차 거르기(운영 DB 읽기 전용): 좌표 행마다 저장된 카카오 결과(장소 이름·주소)로 7가지 오류 유형을 걸렀다. 출처 kakao-v(저장 때 카카오와 엄격 대조, 19,542행)와 출처 kakao 936행은 저장된 카카오 장소 이름·주소가 우리 이름·동과 맞아 1차에서 통과.
- 2차 대조: 걸린 641건을 카카오맵 장소 검색(공식 연결 도구)과 장소 상세(지번·좌표·준공·세대수)로 하나씩 대조. sonnet 에이전트 7개가 공통 지침(`판정 규칙`)으로 수행, 결과 641/641 빠짐·중복 없음.
- 재확인: 좌표 이동 판정 12곳은 DB 좌표와 카카오 상세를 상위 세션이 직접 다시 받아 거리를 재계산(모두 일치). A/B 분리는 에이전트 판정과 엄격 기준(같은 동·아파트 분류·이름 뼈대 포함)이 모두 "하나"인 124묶음만 확정.
